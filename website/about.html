Docker Concepts Learned

  • Image: A read-only template that contains the application code, dependencies and configuration needed to run a program. Containers are created from images, and images are built using a Dockerfile.
  • Container: A running instance of an image. It is an isolated, lightweight process that shares the host machine's OS kernel but has its own filesystem, network and process space.
  • Dockerfile: A text file containing a set of instructions (such as FROM, COPY, RUN, EXPOSE) that Docker reads in order to automatically build an image.
  • Port Mapping: The -p flag (e.g. -p 8080:80) connects a port on the host machine to a port inside the container, allowing traffic sent to the host port to reach the service running in the container.
  • Docker Registry (e.g. Docker Hub): A storage and distribution system for Docker images. Base images like nginx:alpine are pulled from a registry, and custom-built images can be pushed there to be shared or deployed.
  • Layers and Caching: Each instruction in a Dockerfile creates a new image layer. Docker caches unchanged layers, which makes rebuilding an image after a small change much faster.
