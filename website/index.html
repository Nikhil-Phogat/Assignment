What is Docker?

Docker is a platform that packages an application along with everything it needs to run — code, runtime, libraries and system tools — into a single unit called a container. Because the container includes all its dependencies, it runs the same way on any machine that has Docker installed, whether that is a developer's laptop, a test server, or a production cloud environment. This solves the classic “it works on my machine” problem and makes applications easy to build, ship, and deploy consistently.

This entire website is served from inside a Docker container running the nginx:alpine image. See the Contact page for more details and the project's GitHub repository.
